How to Play Kernel Master

💾 Mode 1: Resource Allocation (Banker's Algorithm)

  • Objective: Help all processes finish by granting their required resources (RAM, CPU, Disk, Printer, GPU).
  • The Core Rule: When a process gets its Full Need, click "Run Process". It finishes and returns ALL its allocated resources back to your available pool!
  • Safe State (🟢): There exists an order (Safe Sequence) where every process can eventually finish.
  • Deadlock (⚠️): When available resources run out and every remaining process is waiting on others.

⚡ Mode 2: CPU Scheduling Lab

  • Algorithms: Switch between FCFS, SJF, SRTF, Priority, and Round Robin to compare Waiting Time and Turnaround Time on a dynamic Gantt chart.
  • Benchmark: Click "Compare All" to test which algorithm performs best on the current workload!
